# AGENTS Guide

Chinese version: [`AGENTS_zh.md`](AGENTS_zh.md).

Multilingual Hugo blog (Congo theme) on GitHub Pages. Content uses language suffixes: `*.en.md`, `*.zh.md`.

## Quick commands

- Preview locally: `hugo server`
- Build site: `hugo` (output in `public/`, not source)

# 仓库结构

| 路径 | 用途 |
|------|------|
| `config/_default/` | Hugo 站点配置 |
| `config/_default/menus.en.toml` | 英文导航 |
| `config/_default/menus.zh.toml` | 中文导航 |
| `content/` | 站点正文 |
| `content/tech/` | 技术文章 |
| `content/insights/` | 洞察 / 访谈 |
| `content/series/` | 系列 / 书籍章节 |
| `content/about/` | 关于页 |
| `content/cources/` | 课程笔记（路径拼写保持原样） |
| `content/papers/` | 论文笔记分区 |
| `scripts/` | Markdown 处理、图片、OSS 上传、文章拆分 |
| `.cursor/skills/` | 项目内 Cursor skills |
| `docs/` | Agent 指南（本目录；纳入 git） |
| `.cursor/docs/` | Agent 临时生成的说明文档（gitignore） |
| `public/`、`resources/`、`.hugo_cache/` | 构建产物 / 缓存 — 非源内容 |

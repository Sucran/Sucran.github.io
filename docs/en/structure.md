# Repository structure

| Path | Purpose |
|------|---------|
| `config/_default/` | Hugo site configuration |
| `config/_default/menus.en.toml` | English navigation |
| `config/_default/menus.zh.toml` | Chinese navigation |
| `content/` | All site content |
| `content/tech/` | Technical articles |
| `content/insights/` | Insight / interview posts |
| `content/series/` | Book / series chapters |
| `content/about/` | About page |
| `content/cources/` | Course notes (typo preserved in path) |
| `content/papers/` | Paper notes section |
| `scripts/` | Markdown processing, image handling, OSS upload, article splitting |
| `.cursor/skills/` | Project-local Cursor skills |
| `docs/` | Agent guidance (this folder; committed) |
| `.cursor/docs/` | Ephemeral agent-generated notes (gitignored) |
| `public/`, `resources/`, `.hugo_cache/` | Build output / cache — not source |

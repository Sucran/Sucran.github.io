# Project overview

- **Type:** multilingual personal blog
- **Stack:** [Hugo](https://gohugo.io/) + [Congo](https://github.com/jpanther/congo) theme
- **Languages:** English and Simplified Chinese
- **Deployment:** GitHub Pages
- **Key convention:** most articles and section indexes use language suffixes — `*.en.md` and `*.zh.md`

When adding a new article, provide matching language files when both locales should publish the same content.

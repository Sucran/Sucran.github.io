# Agent documentation

This folder holds detailed guidance for coding agents. It follows the [AGENTS.md](https://agents.md) pattern: keep the root [`AGENTS.md`](../AGENTS.md) small, load these files **on demand**.

| Language | Entry point |
|----------|-------------|
| English | [`AGENTS.md`](../AGENTS.md) → `docs/en/` |
| 中文 | [`AGENTS_zh.md`](../AGENTS_zh.md) → `docs/zh/` |

**Not the same as** `.cursor/docs/` — that directory is for ephemeral, agent-generated notes and is gitignored.
